# ArtisanHub legal terms

The current text of the **ArtisanHub Installer License Agreement**, `installer-license.md`.

The ArtisanHub installer reads the agreement from this repository, so the terms can change without a new
installer release. A changed text binds a user only once they accept it: the installer shows the new version
and asks for acceptance before it goes on.
